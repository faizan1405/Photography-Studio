# PAGE TRANSITION SYSTEM

This is REQUIRED on EVERY PAGE.

When a visitor clicks:

About
Services
Pre Wedding
Sangeet
Mehndi
Wedding Photography
Gallery
Contact

DO NOT instantly switch pages.

Create a cinematic photography transition.

Sequence:

1. Current page slightly freezes.
2. Current page visually compresses into a photograph/frame.
3. A camera-flash effect appears.
4. The captured image briefly fills the screen.
5. Screen flashes warm white.
6. New page begins underneath.
7. New page starts with the LOVE CURTAIN OPENING ANIMATION.
8. Curtains open.
9. New page content reveals using its own page-specific animation.

The effect should feel like:

**CLICK → FLASH → PHOTOGRAPH CAPTURED → CURTAINS OPEN → NEW PAGE**

This transition must work across ALL pages.

Keep it smooth and fast enough that users don't feel delayed.

Target approximately 800–1200ms.

Support browser back/forward navigation properly.

# IMAGE REVEAL SYSTEM

Every major photography image must have a strong reveal animation.

When an image enters the viewport:

1. A mask/panel covers the image.
2. The panel slides away.
3. Image is revealed.
4. Image starts slightly enlarged.
5. Image smoothly settles into its final size.

Example:

Initial:
Image scale = 1.12

Reveal:
Mask slides horizontally/vertically.

Final:
Image scale = 1.0

The effect should feel like a photograph being physically revealed from behind a panel.
